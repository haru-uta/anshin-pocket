# あんしん ポケット — 仕様

会社（訪問看護ステーションはるうた）の利用者さん（ASD のある小児）向けの練習アプリ。2026-10-26 代表と決めた。
決めた順に追記する。仮決めには「(仮)」を付ける。

## 決まったこと
- 名前: あんしん ポケット（2026-10-26 代表選択。名前にモリーは入れない。案内役はモリーのまま）。
- 使う場面: 訪問中にスタッフと練習し、家でも家族と続ける（両方）。
- 機能: 4つ全部を1つのアプリに入れ、タイトルで選ぶ。中身は1つずつ作り、できた順にボタンを出す。
  1. きもちを よもう（犬の表情・しっぽ・耳から気持ちを当てる）
  2. れんしゅう しよう（場面の練習。6場面すべて入れて子どもが選ぶ）
     病院の受診 / 注射・採血 / 歯医者 / 散髪 / はじめての場所 / 訪問看護が来る日
  3. じぶんの カード（にがて・おちつく方法を選んでカードにする）
  4. きょうの よてい（一日の予定を絵で並べる）
- 案内役: モリー（会社の犬）。
- 選べるキャラ: いろいろな犬（モリー・こむぎ(柴)・ミルク(トイプードル)・ココア(ダックス)）。
- 練習の記録: 練習の履歴は残さない。進み具合（レベル・スター・ノート・ショップ）はその端末にだけ保存。
- じぶんノート（2026-10-26 追加）: アバター12人から選ぶ・なまえ（ひらがな/カタカナ6文字）・すきなたべもの/あそび（3つまで）・すきないろ・にがて・おちつく方法。シールを6か所に貼れる。
- レベルとショップ（2026-10-26 追加）: 練習でスターがたまる。ためた合計でレベル（最大20）、スターでシール16・ノートの色8・わく4を買う。使ってもレベルは下がらない。
- あいことば（2026-10-26 追加）: 進み具合をひらがな40文字にしたもの。別の端末で入れると続きから。サーバーに保存しない（会社に利用者さんの情報を持たない）。
- 配り方: 誰でも開けるアドレス（GitHub Pages、検索よけ付き）。

## 守ること
- 時間制限・失敗の罰・急な音や点滅を入れない。音・動き・明るさは「おうちの人・スタッフ」画面で調整。
- 言葉は文字どおり。たとえ話・皮肉を使わない。
- 「ASD が良くなる」「治療」とうたわない（医療機器プログラムに当たるおそれ。配る前に該当性を確認）。
- 職員の絵・利用者さんの情報は入れない。
